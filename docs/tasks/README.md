# Backend Task List

Local task tracker for the Picktime Laravel backend.

## Workflow

1. Start every task from the latest `main`.
2. Create a branch named after the task, without prefixes.
3. Keep the task focused and finish it with a commit.
4. Push the task branch after the commit.
5. Merge back to `main` only after the task is reviewed or accepted.
