# 001 - Scaffold Laravel

## Branch

`scaffold-laravel`

## Goal

Create the initial Laravel API application structure for the Picktime backend.

## Scope

- Install Laravel in the backend repository.
- Configure the project as an API backend.
- Add a clean `.env.example`.
- Keep generated structure compatible with future booking and admin APIs.
- Update the README with setup and development commands.

## Acceptance Criteria

- Laravel boots successfully.
- Dependency installation works through Composer.
- The default test command runs.
- The task is committed and pushed on the `scaffold-laravel` branch.
