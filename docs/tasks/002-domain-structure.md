# 002 - Domain Structure

## Branch

`domain-structure`

## Goal

Create the core backend domain structure for rooms, reservations, availability, and booking rules.

## Scope

- Add models and migrations for rooms and reservations.
- Define reservation statuses.
- Define fixed booking slot rules.
- Add factories where useful for tests and seed data.
- Keep domain code separated from controllers.

## Acceptance Criteria

- Database migrations run successfully.
- Domain classes have clear responsibilities.
- Basic model tests cover relationships and important constraints.
- The task is committed and pushed on the `domain-structure` branch.
