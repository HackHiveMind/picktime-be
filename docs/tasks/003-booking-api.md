# 003 - Booking API

## Branch

`booking-api`

## Goal

Expose the public API needed by the frontend booking flow.

## Scope

- Add endpoints for available dates and time slots.
- Add endpoint for creating a reservation.
- Validate public booking input.
- Return consistent JSON responses.
- Prevent double booking for the same room and slot.

## Acceptance Criteria

- Public booking endpoints are documented in the README or route notes.
- Validation errors return useful JSON responses.
- Double booking is rejected.
- Feature tests cover success and failure paths.
- The task is committed and pushed on the `booking-api` branch.
